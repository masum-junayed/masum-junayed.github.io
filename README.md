# Masum Shah Junayed — Academic Portfolio

A lightweight academic portfolio designed for GitHub Pages.

## 1. Add your profile photo
Replace `assets/profile-placeholder.svg` with your own photo, for example `assets/profile.jpg`.
Then change this line in `index.html`:

```html
<img src="assets/profile-placeholder.svg" alt="Masum Shah Junayed profile placeholder" />
```

to:

```html
<img src="assets/profile.jpg" alt="Masum Shah Junayed" />
```

## 2. Add your CV
Place your PDF at:

`assets/Masum_Shah_Junayed_CV.pdf`

The CV button is already connected to this file.

## 3. Update links/content
Edit `index.html` to add your Google Scholar, GitHub, university profile, more publications, and recent news.

## 4. Publish with GitHub Pages
1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload all files from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save. Your site will appear at `https://<your-github-username>.github.io/`.

## Files
- `index.html` — content and structure
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation + year
- `assets/` — profile image and CV
