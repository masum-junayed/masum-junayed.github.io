# Masum Shah Junayed — Academic Portfolio

Updated GitHub Pages portfolio populated from the supplied LaTeX CV.

## To update the live website
Replace the existing files in the root of `masum-junayed.github.io` with:
- `index.html`
- `styles.css`
- `script.js`
- `assets/`

The supplied LaTeX CV is included in `assets/Masum_Shah_Junayed_CV.tex`.

For a profile photo, replace `assets/profile-placeholder.svg` and update the `img src` in `index.html`.
